## Tasks Completed

### Task 1: Iris Flower Classification
- **Objective:** Classify iris flowers into three species (*Setosa*, *Versicolor*, *Virginica*) based on sepal and petal dimensions.
- **Algorithm:** K-Nearest Neighbors (KNN)
- **Directory:** `Task_1_Iris_Classification/`

### Task 2: Spam Mail Detector
- **Objective:** Classify text messages as spam or ham (non-spam) using Natural Language Processing.
- **Dataset:** UCI SMS Spam Collection (fetched dynamically via script)
- **Feature Extraction:** TF-IDF Vectorization
- **Algorithm:** Multinomial Naive Bayes
- **Performance:**
  - **Accuracy:** 97.67%
  - **Spam Precision:** 1.00
  - **Spam Recall:** 0.83
- **Directory:** `Task_2_Spam_Detector/`
